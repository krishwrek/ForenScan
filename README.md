# ForenScan: Explainable Image Forensics Web Application

**ForenScan** is an explainable, multi-modal digital image forensics suite engineered using classical **Image Processing Analysis (IPA)** and lightweight, interpretable machine learning. It is designed to detect:
1. **AI-Generated / Synthetic Images** (Diffusion models, GANs, VAEs)
2. **Locally Edited / Inpainted Regions** (Object insertions, removals, feathering)
3. **Copy-Move & Splicing Tampering** (Cloned textures, composites with conflicting illumination)

Unlike opaque "black-box" deep neural networks that only output a binary label without justification, ForenScan provides **verifiable, physical, and mathematical explanations** for every forensic finding, supported by multi-modal heatmaps, frequency spectra, and quantitative metrics.

## Key Features

1. **Error Level Analysis (ELA):**
   - Re-compresses image at JPEG Quality 95 to amplify quantization error differences across regions.
   - Spliced elements or inpainted regions with mismatched compression histories stand out with elevated error levels.

2. **Sensor Noise Consistency:**
   - Physical camera sensors exhibit Poisson/Gaussian shot noise (PRNU) uniformly across the frame.
   - Computes local noise variance via Donoho's Median Absolute Deviation (MAD) on high-pass residuals to flag anomalous blocks.
   - Detects synthetic AI smoothing and denoise artifacts.

3. **Multi-Operator Edge Analysis:**
   - Computes Canny edges, Sobel gradient magnitudes, and Laplacian second derivatives.
   - Measures regional edge sharpness and sharpness discrepancy ratios to catch scissor borders and feathering halos.

4. **Frequency-Domain Analysis (2D FFT & 8x8 DCT):**
   - Detects periodic lattice spikes generated by transposed convolution and latent pixel upsampling layers in GAN and Diffusion models.
   - Evaluates azimuthal radial power-law decay ($\alpha \approx 1.6 - 2.4$ in natural photos).

5. **Color & Lighting Consistency:**
   - Computes RGB/HSV histograms and fits 2D planar illumination gradients ($Y(x, y) = ax + by + c$) across image quadrants.
   - Detects conflicting light source angles indicating composited subjects from different environments.

6. **Copy-Move Forgery Detection:**
   - Extracts 12-dimensional color-texture descriptors from overlapping patches.
   - Utilizes nearest-neighbor queries and shift-vector spatial clustering to confirm duplicated patches.

7. **Multi-Modal Fused Heatmap:**
   - Combines ELA, noise inconsistency, edge sharpness anomalies, and copy-move matches into a single alpha-blended overlay on the original image with bounding boxes.

8. **Calibrated Random Forest & Rule-Based Fallback:**
   - 25-dimensional standardized numerical feature vector.
   - Includes a trained Random Forest model and a standalone rule-based heuristic system for guaranteed offline execution without dependencies on large models.

9. **Publication-Grade Reporting:**
   - Generates court-admissible-grade PDF reports with ReportLab, including SHA-256 hashes, visual exhibits, anomaly tables, and metadata audits.
   - Exports complete feature manifests to CSV.

## Installation & Setup

### Prerequisites
- Python 3.9+ (Python 3.10, 3.11, 3.12, or 3.15 supported)
- CPU-only execution (No GPU or CUDA required)

### Step 1: Clone or Navigate to Directory
```bash
cd "ipa project"
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 3: Generate Assets & Train Model (Optional if already present)
```bash
python create_sample_assets.py
```

### Step 4: Launch ForenScan Web Application
```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.

## Usage Guide

1. **Input Mode:**
   - **Upload Image:** Upload your own JPG, PNG, or WEBP image.
   - **Load Demo Sample Case:** Choose from the pre-packaged forensic scenarios (Authentic, Spliced, Copy-Move, AI-Generated) for instant demonstration.
2. **Tune Sensitivity (Sidebar):**
   - Adjust the **Anomaly Sensitivity Multiplier** (0.5 to 2.0) to modulate outlier thresholds.
   - Adjust **ELA Quality** (default 95) or **Block Size** (16, 32, 64px).
3. **Explore Analysis Tabs:**
   - **Visual Overview:** Inspect original, ELA heatmap, and annotated suspicious regions.
   - **ELA & Noise:** Review compression error distributions and sensor noise variance maps.
   - **Edges & Frequency:** Inspect 2D FFT magnitude spectrum and radial decay curve.
   - **Color & Lighting:** Check RGB/HSV histograms and quadrant lighting angles.
   - **Copy-Move:** View duplicated patches and shift vectors.
   - **Explainable Findings:** Review clear forensic evidence items with severity levels.
   - **EXIF Metadata:** Inspect hardware tags, GPS geotags, and software signatures.
   - **Feature Manifest:** Inspect the 25 numerical metrics and forensic radar chart.
   - **Download Reports:** One-click download of the official PDF report or CSV data manifest.

## Recommended Benchmark Datasets

To evaluate or train ForenScan on academic forensic benchmarks:
- **CASIA Image Tampering Detection (CASIA v1.0 & v2.0):** Comprehensive benchmark for splicing and copy-move tampering.
- **CoMoFoD:** Standard benchmark dedicated to copy-move forgery with post-processing attacks (blurring, noise, rotation).
- **Columbia Uncompressed Splicing Dataset:** Real uncompressed image splices for edge and illumination validation.
- **Coverage Dataset:** Copy-move database with certified ground-truth masks.
- **DiffusionDB / Midjourney Benchmark:** Curated sets of AI-generated images vs. real photographs for frequency artifact evaluation.

## Limitations

- **Aggressive Social Media Compression:** Platforms like WhatsApp, Instagram, and Twitter recompress images heavily and strip all EXIF metadata. Severe recompression can attenuate subtle sensor noise patterns and ELA differentials.
- **Multi-Source Panoramic Stitching:** Authentic camera panoramic stitches may produce localized edge or lighting discrepancies along stitch seams that mimic splicing.
- **Ultra-High-Resolution Gigapixel Images:** Images above 4K are scaled to 1024px maximum dimension for responsive CPU execution; minute sub-pixel edits may require analyzing localized 1024px crops at native resolution.
